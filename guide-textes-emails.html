Guide : modifier les textes des emails automatiques

Tout ce qu'il faut savoir pour changer un email sans rien casser. Temps de lecture : 5 minutes.

1. Où se trouvent les textes ?

  1. Va dans Shows, clique sur Challenge 3 jours (ou 5 jours), puis sur le bouton ✉️ Textes des emails. Tu peux aussi passer par le lien en haut de la page des inscrits.
  2. À gauche : la liste des emails, rangés par phase (Avant, Durant, Après, Suivi).
  3. À droite : l'éditeur de l'email choisi, et en dessous son aperçu, exactement comme le client le verra.

2. Modifier un email, étape par étape

  1. Clique sur l'email dans la liste de gauche.
  2. Modifie le Sujet (la ligne que le client voit dans sa boîte mail).
  3. Modifie le Texte : clique à l'endroit voulu et tape normalement.
  4. Vérifie le résultat dans l'aperçu en dessous.
  5. Quand le texte te convient, coche « Texte validé ».
  6. Clique sur Enregistrer. Le message « Enregistré ✔ » confirme la sauvegarde.
✅ Bon à savoirLe nouveau texte est utilisé pour les prochains envois. Les emails déjà partis ne changent pas.

3. Les zones automatiques (entre accolades)

Ces zones sont remplacées automatiquement pour chaque personne. Pour en ajouter une, clique sur son bouton sous le texte : elle s'insère à l'endroit du curseur.

ZoneRemplacée parExemple
{{prenom}}Le prénom du clientAïcha
{{titre_challenge}}Le nom du challengeChallenge Guérison Roqya
{{date_debut}}Le premier jour du challengejeudi 1 octobre
{{heure_direct}}L'heure du direct20h00
{{jours_restants_texte}}Le nombre de jours avant le début2 jours / 1 jour
{{lien_direct}}Le lien Zoom du direct(lien du challenge)
{{lien_replay}}Le lien du replay(lien du challenge)
{{lien_rdv}}Le lien de prise de rendez-vous (Calendly)(lien du challenge)
⚠️ AttentionÉcris les zones exactement comme dans le tableau : deux accolades de chaque côté, sans espace, sans accent. {{prenom}} fonctionne, {prenom} ou {{ Prénom }} ne fonctionnent pas : le client verrait le texte tel quel.

4. Les petits codes de mise en page

Le texte contient quelques codes entre chevrons. Ils servent uniquement à la mise en page.

CodeRôle
<p> … </p>Un paragraphe (un bloc de texte avec un espace en dessous)
<b> … </b>Met le texte en gras
<br>Retour à la ligne, sans espace

Exemple : pour changer « un cahier » en « un carnet », ne modifie que le mot :

<p>Conseil : prépare un carnet et un stylo.</p>
⛔ À ne pas faireNe supprime jamais un <p> sans son </p>, ni un <b> sans son </b>. Tout le reste de l'email risquerait de s'afficher en gras ou collé. Si l'aperçu devient bizarre, annule ta dernière modification avec Ctrl + Z.

5. Les boutons cliquables

Le bouton + Bouton insère un bouton prêt à l'emploi. Change seulement le texte « Texte du bouton ». Pour changer sa destination, remplace {{lien_direct}} dans le code du bouton par {{lien_replay}} ou {{lien_rdv}}.

⚠️ Les liens viennent du challengeLes liens Zoom, replay et rendez-vous sont enregistrés dans chaque challenge, pas dans le texte. Si un bouton ne mène nulle part, c'est que le lien n'a pas encore été rempli pour ce challenge.

6. Points d'attention avant un vrai lancement

  • Tous les emails doivent être « Validé » (badge vert) avant d'activer un challenge.
  • Les textes sont communs à tous les challenges du même type. Évite les dates écrites en dur : utilise {{date_debut}} et {{heure_direct}}.
  • Pour l'instant, les textes existent en français uniquement. Les autres langues seront ajoutées plus tard.
  • Avant une grosse modification, copie l'ancien texte (Ctrl + A, puis Ctrl + C) dans une note, pour pouvoir revenir en arrière.
  • Les emojis (🔥 ✅ 📅) fonctionnent dans le sujet et dans le texte.
  • Le sujet doit rester court : environ 60 caractères, sinon il est coupé sur téléphone.
  • Le Replay n'est pas envoyé au groupe Midi, et les emails de Suivi ne sont pas envoyés aux acheteurs. C'est automatique, rien à écrire pour ça.

7. Tester un email modifié

La simulation permet de recevoir l'email dans ta propre boîte avant les clients. Demande à Claude de relancer le test sur le challenge de test : l'email arrive avec la mention [TEST] dans le sujet.
