Guide : modifier les textes des emails automatiques

Tout ce qu'il faut savoir pour changer un email sans rien casser. Temps de lecture : 4 minutes.

1. Où se trouvent les textes ?

  1. Va dans Shows, clique sur Challenge 3 jours (ou 5 jours), puis sur le bouton ✉️ Textes des emails. Tu peux aussi passer par le lien en haut de la page des inscrits.
  2. À gauche : la liste des emails, rangés par phase (Invitation, Avant, Durant, Après, Suivi).
  3. À droite : l'éditeur de l'email choisi, et en dessous son aperçu, exactement comme le client le verra.

2. Modifier un email, étape par étape

  1. Clique sur l'email dans la liste de gauche.
  2. Modifie le Sujet (la ligne que le client voit dans sa boîte mail). Juste en dessous, tu vois le sujet avec un exemple de prénom.
  3. Clique directement dans l'email et écris, comme dans Word. Entrée crée une nouvelle ligne, Retour arrière efface.
  4. Pour mettre des mots en gras : sélectionne-les, puis clique sur G Gras.
  5. Quand le texte te convient, coche « Texte validé », puis clique sur Enregistrer. Le message « Enregistré ✔ » confirme la sauvegarde.
✅ Bon à savoirLe nouveau texte est utilisé pour les prochains envois. Les emails déjà partis ne changent pas. Si tu t'es trompé avant d'enregistrer, recharge simplement la page.

3. Les étiquettes dorées (zones automatiques)

Les étiquettes dorées comme Prénom ou Date de début sont remplacées automatiquement pour chaque personne. Pour en ajouter une : clique à l'endroit voulu dans l'email, puis sur l'étiquette dans la ligne Zones automatiques.

4. Les objets : bouton, image, encadré, séparateur, signature

  1. Ajouter : clique dans l'email sur la ligne après laquelle tu veux l'objet, puis sur le bouton noir (🔘 Bouton, 🖼️ Image, 📦 Encadré, ➖ Séparateur, ✍️ Signature).
  2. Image : choisis d'abord la taille (Petite, Moyenne, Grande), puis la photo sur ton ordinateur. Elle est envoyée et placée automatiquement.
  3. Choisir un objet : clique dessus. Un cadre doré l'entoure et une barre apparaît au-dessus de l'email.
  4. Dans cette barre : ⬆️ Monter / ⬇️ Descendre pour le déplacer, 🗑️ Supprimer pour l'enlever. Pour une image : sa taille. Pour un bouton : son texte et sa destination (Mène vers : direct, replay, rendez-vous ou inscription).
⚠️ Les liens viennent du challengeLes liens Zoom, replay, rendez-vous et inscription sont enregistrés dans chaque challenge (bouton ✏️ Modifier le challenge), pas dans le texte. Si un bouton ne mène nulle part, c'est que le lien n'a pas encore été rempli pour ce challenge.

5. La signature commune

Tout en haut de la liste se trouve Signature (commune à tous les emails). Modifie-la une seule fois : tous les emails qui contiennent le cadre pointillé « Signature » l'utilisent automatiquement.

6. Points d'attention avant un vrai lancement

  • Tous les emails doivent être « Validé » (badge vert) avant d'activer un challenge.
  • Les textes sont communs à tous les challenges du même type. Évite les dates écrites en dur : utilise les étiquettes Date de début et Heure du direct.
  • Pour l'instant, les textes existent en français uniquement. Les autres langues seront ajoutées plus tard.
  • Avant une grosse modification, copie l'ancien texte (Ctrl + A, puis Ctrl + C) dans une note, pour pouvoir revenir en arrière.
  • Les emojis (🔥 ✅ 📅) fonctionnent dans le sujet et dans le texte.
  • Le sujet doit rester court : environ 60 caractères, sinon il est coupé sur téléphone.
  • Le Replay n'est pas envoyé au groupe Midi, et les emails de Suivi ne sont pas envoyés aux acheteurs. C'est automatique, rien à écrire pour ça.

7. Tester un email modifié

La simulation permet de recevoir l'email dans ta propre boîte avant les clients. Demande à Claude de relancer le test sur le challenge de test : l'email arrive avec la mention [TEST] dans le sujet.
